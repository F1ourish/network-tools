# Проверка Network Tools 1.5.1

Дата: 08.10.2026. Статус: кандидат; проверка Windows ещё не завершена.

## Проверяемые изменения

- Повторная генерация сохраняет включённый и выключенный флажок «Показать».
- Ошибка источника случайности очищает прежний пароль, сохраняя состояние показа.
- «Сбросить» восстанавливает точный DEFAULT_SYMBOLS после ручного изменения,
  пустого и ошибочного ввода; устаревший результат очищается.
- Другие параметры не меняются; выключенная группа спецсимволов остаётся выключенной.
- При стандартном наборе кнопка отключена; повторный сброс не очищает текущий пароль.
- Настоящий EXE: ручной список, восстановление клавиатурой и восстановление после ошибки.

Итоговые результаты будут дополнены после CI и проверки артефактов.
