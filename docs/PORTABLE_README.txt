Network Tools 1.8.2 - Windows x64

Распаковать ZIP и запустить NetworkTools.exe.
Установка Python не требуется. Можно перенести один EXE в пользовательский каталог.

MAC: 4 формата и выбор регистра.
IPv4: сеть/IP, маска или CIDR, wildcard, binary mask, broadcast и страницы хостов.
MTU/MSS: IP/L2 размер, dot1q/QinQ, PPPoE, GRE, WireGuard, VXLAN, ESP, OpenVPN, L2TP/IPsec.
Выбрать профиль и параметры; показать overhead, внутренний MTU, MSS и кадр с FCS.
Маршруты: longest prefix match в введённом списке CIDR.
ACL: постоянные поля in слева и out справа для одного интерфейса, оба IPv4 и порта, TCP/UDP.
Выбор стороны интерфейса определяет ACL запроса и ответа; текст и флажки остаются при своих списках.
eq/neq поддерживают до 10 портов: eq www 443 означает 80 или 443; neq 22 3389 исключает оба.
В отчёте показаны имя списка, направление in/out и первое совпавшее правило.
Первое правило permit/deny или неявный deny определяет результат; показана причина.
У ответа меняются IP/порты. Неизвестный нужный порт требует уточнения.
«Развернуть» или Ctrl+Enter в поле ACL - большой редактор; Escape - вернуться.
Ctrl+L в большом редакторе выделяет весь список для замены или копирования.
Номера слева - физические строки; sequence - номер правила Cisco. Ошибка подсвечивается.
Вставка убирает пробелы по краям строк и (N matches); прокрутка видна по необходимости.
Флажок «ACL в этом направлении не назначена» сохраняет текст и пропускает этот фильтр.
Сверить сторону интерфейса и подсказки ip access-group <name> in/out:
со стороны источника запрос in, ответ out; со стороны назначения запрос out, ответ in.
«IP-группы» - отдельное окно состава object-group network для обеих ACL.
Вставить show object-group или конфигурацию групп: host, подсеть с маской/CIDR, any, group-object.
Можно добавить заголовок группы по имени и вставить список адресов под ним.
В IP-группах используется маска подсети, в ACL - wildcard. Имена учитывают регистр.
Отсутствующие/пустые группы и циклы дают ошибку; IPv6, DNS и группы сервисов не поддерживаются.
Совпавший участник группы виден в заключении. Текст сохраняется до закрытия приложения.
Вставка полного вывода Cisco убирает prompts/команды show/счётчики; заголовок сохраняет тип/имя ACL.
«Очистить вывод» обрабатывает уже вставленный текст; ошибочные правила не удаляются.
Проверка одного wildcard доступна в дополнительном блоке.

Свободные IP: указать сеть/IP с CIDR или маской и вставить ARP-вывод/список IPv4.
Строки без IPv4 и команды просмотра удаляются при вставке; ошибочные IP остаются для проверки.
По умолчанию исключены .33, .34. Список через запятую; диапазон .50-.60 или 192.0.2.100-192.0.2.110.
Короткие записи задают последний октет во всей подсети; полный IPv4 - конкретный адрес.
Пустое поле отключает ручные исключения. Дубликаты и пересечения не считаются дважды.
Кандидаты показаны по 100: «Копировать IP» - страница, «Все IP» - список до 10000, «Отчёт» - расчёт.
Подсети /1-/32; /31 содержит оба адреса, /32 - один. ARP вне подсети учитывается отдельно.
Отсутствие в ARP не подтверждает свободный IP: перед назначением сверить IPAM/DHCP и проверить конфликт.
ARP и исключения не сохраняются. Сетевые запросы приложение не отправляет.

CUCME: редактор и результат заполняют окно; разделитель меняет их высоту.
Кнопка «Развернуть» рядом с каждой областью открывает её отдельно. Ввод синхронизируется.
F4 - конфиг; F6 - результат; F8 - отдельное окно замечаний; Ctrl+Enter - развернуть.
Поиск: телефон, номер ephone/DN, часть name/label/описания. button задаёт привязку.
Карточка: номер, описание, аппарат, MAC/type и настроенные call-forward.
Переадресации DN-template наследуются; прямые настройки DN имеют приоритет.
«Свободные номера»: парная таблица ephone/ephone-dn для каждого номера диапазона.
✓ секция не создана; ✗ секция/ссылка существует или номер выше max-dn.
Равные номера в строке не означают привязку. Пустая/FREE секция тоже существует.
SIP/шаблоны не блокируют таблицу секций; ограничения телефонов объясняются в замечаниях.
«Все строки» и Ctrl+A/C копируют TSV; список целиком до 10000 строк.
Конфиг хранится в памяти до очистки/закрытия. Очистка удаляет undo обоих редакторов.

Ctrl+1…8 - вкладки. Ctrl+L - первое поле. Ctrl+Shift+C - результат инструмента.
Ctrl+Shift+T - дневная/ночная тема. Ctrl+A/C/V - выделение/копирование/вставка.

Результат обновляется при вводе. При ошибке старый результат очищается.
Окно списка хостов отображает снимок подсети, по 100 адресов на странице.
Только тема сохраняется в %APPDATA%\MacAddressConverter\settings.json.
Введённые адреса не сохраняются. Приложение не обращается к сети.

Расчёты не заменяют проверку конфигурации оборудования. MTU пути не измеряется;
маршрутизация VRF/PBR, NAT, stateful firewall и фрагменты не моделируются.
Неподдерживаемые условия ACL дают ошибку. TCP established проверяет ACK/RST.
Вставка: кнопка заменяет поле; Ctrl+V/Shift+Insert/меню вставляют по курсору.
Поддерживаются многострочные маршруты/ACL/ARP и русская раскладка Windows.
Целевая среда - Windows 10/11 x64. Проверка выполнена на Windows CI;
разные клиентские Windows и DPI требуют отдельной проверки. EXE без подписи.

Пароли: 20 символов по умолчанию, CSPRNG, выбранные группы обязательны.
Показать/Copy/Очистить; автоочистка собственного буфера через 30 с, пока приложение открыто.
Состояние «Показать» сохраняется при повторной генерации.
«Сбросить» рядом со спецсимволами восстанавливает стандартный набор и очищает старый результат.
Кнопка доступна, когда список отличается от исходного; другие параметры не меняются.
Пароли не сохраняются. История буфера Windows не очищается.
F1 или «Помощь» - назначение, шаги, примеры и ограничения активной вкладки.

Крупные поля: маршруты, ACL, свободные IP и CUCME заполняют окно автоматически.
Захват у горизонтального края меняет высоту; у бокового - ширину; в углу - оба размера.
Двойной щелчок по захвату возвращает автоматический размер.
«Развернуть» и Ctrl+Enter открывают редактор/результат отдельно. Escape - вернуться.
Редакторы маршрутов и ARP синхронизируются с вкладкой; результаты обновляются вместе с расчётом.
