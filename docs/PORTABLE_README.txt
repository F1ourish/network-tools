Network Tools 1.2.0 — Windows x64

Распаковать ZIP и запустить MacAddressConverter.exe.
Установка Python не требуется. Можно перенести один EXE в пользовательский каталог.

MAC: 4 формата и выбор регистра.
IPv4: сеть/IP, маска или CIDR, wildcard, binary mask, broadcast и страницы хостов.
MTU/MSS: IPv4/IPv6, инкапсуляция вручную.
Маршруты: longest prefix match в введённом списке CIDR.
ACL wildcard: совпадение IPv4 с адресным условием, включая прерывистые маски.

Ctrl+1…6 — вкладки. Ctrl+L — первое поле. Ctrl+Shift+C — результат инструмента.
Ctrl+Shift+T — дневная/ночная тема. Ctrl+A/C/V — выделение/копирование/вставка.

Результат обновляется при вводе. При ошибке старый результат очищается.
Окно списка хостов отображает снимок подсети, по 100 адресов на странице.
Только тема сохраняется в %APPDATA%\MacAddressConverter\settings.json.
Введённые адреса не сохраняются. Приложение не обращается к сети.

Расчёты не заменяют проверку конфигурации оборудования. MTU пути не измеряется;
маршрутизация VRF/PBR и действия/порядок ACL не моделируются.
Целевая среда — Windows 10/11 x64. Проверка выполнена на Windows CI;
разные клиентские Windows и DPI требуют отдельной проверки. EXE без подписи.

Пароли: 20 символов по умолчанию, CSPRNG, выбранные группы обязательны.
Показать/Copy/Очистить; автоочистка собственного буфера через 30 с, пока приложение открыто.
Пароли не сохраняются. История буфера Windows не очищается.
F1 или «Помощь» — назначение, шаги, примеры и ограничения активной вкладки.
