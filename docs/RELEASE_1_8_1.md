**Network Tools 1.8.1** - единое управление размерами крупных полей.

### Изменения

- Ввод и результат в ACL и свободных IP заполняют свободную площадь окна; маршруты и CUCME используют такое же поведение.
- Захваты у краёв меняют высоту или ширину, в углу - оба размера. Результат CUCME растягивается за собственный верхний край и угол.
- Между соседними областями площадь перераспределяется. Изменения ограничены размером страницы; двойной щелчок возвращает автоматический размер.
- Одинаковая кнопка «Развернуть» у каждого крупного ввода и результата. Вместо одиночной стрелки CUCME используется полная подпись.
- Большие редакторы маршрутов и ARP синхронизируют изменения с вкладкой. Большие результаты маршрутов, ACL и свободных IP обновляются вместе с расчётом, ошибкой и страницей.
- Ctrl+Enter открывает поле отдельно, Escape возвращает во вкладку. Данные сохраняются при изменении размеров и закрытии дополнительного окна.

### Обновление и проверка

Распаковать `NetworkTools-1.8.1-windows-x64.zip` и запустить `NetworkTools.exe`.
Python не требуется. Настройки темы совместимы; введённые конфиги и ARP не сохраняются на диск.

Linux Ruff/тесты логики, полный Windows pytest с обязательным GUI,
PyInstaller и настоящий EXE от стандартного пользователя.
Проверка включает перетаскивание мышкой, возврат двойным щелчком,
большие редакторы, readonly результатов, синхронизацию и копирование.
Результаты: [`RELEASE_VERIFICATION.json`](https://github.com/F1ourish/network-tools/releases/download/v1.8.1/RELEASE_VERIFICATION.json).
Хеши: [`SHA256SUMS.txt`](https://github.com/F1ourish/network-tools/releases/download/v1.8.1/SHA256SUMS.txt).

Целевая среда - Windows 10/11 x64; нативный стенд - Windows Server CI.
