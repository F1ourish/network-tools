# Проверка Network Tools 1.8.2

Дата: 20.10.2026. Статус: кандидат; результаты Windows и публикации ожидаются.

- Linux Ruff check/format и 620 тестов без GUI успешны.
- В полном Windows наборе предусмотрены 783 теста, включая 163 GUI.
- Проверка готового EXE предусматривает 79 нативных проверок.
- Подтверждённые результаты конкретной сборки будут в `RELEASE_VERIFICATION.json` и artifacts CI.

## Списки портов

eq/neq принимают 1-10 имён/номеров, отдельно для источника и назначения.
Проверяются все члены eq, исключение всех членов neq, совместная фильтрация портов,
границы 0/65535, десять/одиннадцать элементов, ошибки второго порта и неизвестных условий.
Исходное правило, sequence и физическая строка сохраняются; первое совпадение не меняется.
Списки корректно завершаются перед host/any/wildcard/IP-группой, established и log.

## Направления интерфейса

Поля постоянно соответствуют in/out. check_interface_acls выбирает список запроса
и ответа по стороне интерфейса и переводит ошибки в физический индекс редактора.
GUI проверяет настоящий пересчёт при смене стороны, сохранение текста и флажков,
синхронную подсветку основного/большого редактора, сброс примера и копирование.
В синтетическом примере интерфейса назначения неизвестный порт клиента не мешает
запросу совпасть с out/250 и ответу с in/10. Без разрешающего завершающего правила
тот же запрос получает неявный deny.

## Нативный EXE

Новые сценарии повторяют вставку полного Cisco show с eq www 443, оба варианта
порта, несовпадение, source eq/neq и неизвестный порт. Интерфейс назначения
проверяется с именованными in/out, точными sequence, сменой стороны и out deny.
Флажок отсутствия out отключает и возвращает только соответствующий список.
Прежние сценарии всех восьми вкладок, буфера обмена, крупных полей и CUCME сохранены.

Пользовательские конфиги и снимки в публичные тесты не включены.
Целевая среда - Windows 10/11 x64; фактический нативный стенд - Windows Server CI.
Клиентские Windows, DPI 125-200%, Wine и macOS отдельно не проверялись.
