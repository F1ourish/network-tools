**Network Tools 1.9.0** - проверка конкретного IPv4 по ARP.

### Что добавлено

- На вкладке «Свободные IP» рядом с исключениями появилось поле **«Проверить конкретный IPv4»** с обычным вводом и вставкой из буфера.
- Результат показывает: найден в ARP, кандидат на свободный, исключён, адрес сети, broadcast или вне выбранной подсети.
- Используются те же ARP, подсеть, маска и исключения, что и для общего списка. Совпадение точное: `.1` не совпадает с `.10` или `.100`.
- Изменение данных пересчитывает введённый адрес. Пустой/ошибочный ARP убирает прежнее заключение; ошибка только в проверяемом адресе сохраняет основной список и страницу.
- «Отчёт» и Ctrl+Shift+C включают текущую проверку. «Пример» показывает `192.0.2.3`; справка обновлена.

### Использование

Вставить ARP, указать подсеть и исключения, затем полный IPv4 для проверки.
Отсутствующий в списке адрес отмечается **«Кандидат на свободный по ARP»**,
если подходит подсети и не исключён. Отсутствие записи не подтверждает, что IP
не используется: перед назначением сверить IPAM/DHCP и проверить конфликт.
Сетевые запросы приложение не выполняет; данные остаются в памяти до закрытия.

Распаковать `NetworkTools-1.9.0-windows-x64.zip` и запустить `NetworkTools.exe`.
Python не требуется. Результаты проверки конкретного файла:
[`RELEASE_VERIFICATION.json`](https://github.com/F1ourish/network-tools/releases/download/v1.9.0/RELEASE_VERIFICATION.json).
Хеши: [`SHA256SUMS.txt`](https://github.com/F1ourish/network-tools/releases/download/v1.9.0/SHA256SUMS.txt).

Целевая среда - Windows 10/11 x64; нативный стенд - Windows Server CI.
