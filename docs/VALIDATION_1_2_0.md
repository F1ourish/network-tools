# Проверка Network Tools 1.2.0

Дата: 07.10.2026. Проверка исходников и сборка Windows выполняются до публикации.

Локальные non-GUI тесты проверяют прежние расчёты/CLI, все комбинации групп пароля,
длины 8/20/128, недопустимые параметры, исключения, дедупликацию, rejection sampling,
отказ CSPRNG без fallback, точный размер пространства и примеры справки.

GUI-тесты проверяют скрытый и readonly результат, настройки, копирование,
автоочистку только своего буфера, очистку устаревших результатов, ошибки,
сохранение только темы, Ctrl+6, F1, Escape и помощь каждой вкладки.

Win32 smoke проверяет готовый onefile EXE от обычного пользователя, все прежние
инструменты, генерацию/регенерацию, группы, изменения длины, invalid clear,
clipboard, пустой генератор после перезапуска, справку и темы.
Случайные пароли тестового запуска не входят в отчёты или скриншоты.

Источник фактических чисел, commit и хеша опубликованного EXE:
RELEASE_VERIFICATION.json в assets релиза и связанный workflow run.

Не покрыты отдельно Windows 10/11, DPI 125–200%, Defender/SmartScreen,
корпоративные политики и история clipboard. История 1.1.0 сохранена отдельно.
