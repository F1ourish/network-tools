**Network Tools 1.7.0** - CUCME: поиск аппаратов и свободных ресурсов.

### Изменения

- Восьмая вкладка CUCME с общим конфигом для двух режимов: «Поиск / проверка» и «Свободные номера».
- Поиск по телефону из number/secondary/description DN, ephone/ephone-dn ID и частям имени.
  Имя проверяется одновременно в name, label и description аппарата, без учёта регистра.
- Связи ephone -> button -> ephone-dn с description, number, secondary, name/label, type и MAC.
  Различающиеся поля сохранены; показаны все совпадения и все связанные аппараты.
- Свободные ID ephone-dn, ID ephone и телефонные номера в заданном диапазоне.
  Пустые существующие секции и DN, упомянутые в button, остаются занятыми.
- Несколько кнопок, общие DN, overlay o/c и ссылки x на кнопку; диагностика физических строк.
- Конфиг сохраняется в памяти при поиске, ошибках и переключениях до явной очистки или закрытия.
  На диск не записывается; очистка также удаляет undo редактора.
- Ctrl+8, F1, страницы, копирование отчёта и свободного списка до 10000 значений.

Работа с предоставленным снимком SCCP; фактическая регистрация и линия не проверяются.
Полный конфиг, ёмкость и допустимые ID необходимо сверить перед назначением.
SIP/шаблоны и точечные шаблоны номеров не разворачиваются; соответствующий поиск
свободных ресурсов блокируется. Подробнее: [CUCME](https://github.com/F1ourish/network-tools/blob/main/docs/CUCME.md).

### Обновление и проверка

Распаковать `NetworkTools-1.7.0-windows-x64.zip` и запустить `NetworkTools.exe`.
Python не требуется. Настройка темы совместима с предыдущими версиями.

Linux lint/format и тесты логики, полный pytest Windows с обязательным GUI,
сборка PyInstaller и проверки настоящего EXE от стандартного пользователя.
Фактические результаты и source commit:
[`RELEASE_VERIFICATION.json`](https://github.com/F1ourish/network-tools/releases/download/v1.7.0/RELEASE_VERIFICATION.json).
Контрольные суммы:
[`SHA256SUMS.txt`](https://github.com/F1ourish/network-tools/releases/download/v1.7.0/SHA256SUMS.txt).

Целевая среда - Windows 10/11 x64; нативный стенд CI - Windows Server.
EXE без цифровой подписи. Клиентская приёмка и DPI проверяются отдельно.
