# Проверка Network Tools 1.9.2

Дата: 05.11.2026. Статус: подготовлено; проверка Windows и публикация ожидаются.

План проверки:

- Ruff check/format и 662 теста логики.
- Полный Windows набор: 842 теста, включая 180 GUI, без пропусков.
- 84 проверки готового EXE, включая выбор /0, /25, /32 и возврат к /24 из нового меню.
- GUI-выбор всех 33 вариантов, полный адрес маски в поле, корректные subnet/wildcard/host ranges.
- Ручной ввод 24, /24 и полной маски, выделение соответствующего пункта при открытии списка.
- Вставка и ввод IP/CIDR, последующее изменение маски, очистка ошибочных результатов и восстановление.
- Снимок раскрытого меню `ipv4-mask-menu-day.png`, обе темы и сохранение остальных вкладок.
- Проверка source commit, тега, размеров и SHA-256 всех четырёх assets; EXE и отчёт внутри ZIP совпадают с отдельными файлами.

Расчётные функции IPv4 не менялись; отображаемый пункт меню преобразуется
в префикс в слое интерфейса. Синтетические примеры не содержат рабочих конфигов.
Целевая среда - Windows 10/11 x64. Нативная проверка выполняется в Windows Server CI.
