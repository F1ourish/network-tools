Первый опубликованный релиз **Network Tools 1.1.0**: набор локальных утилит для сетевого инженера.

### Добавлено

- IPv4-калькулятор: по умолчанию 192.168.1.0/24; IP/CIDR, выбор префикса или полной маски,
  проверка адреса сети, отдельные subnet, host range, broadcast, binary mask и wildcard.
- Особые случаи /31, /32 и /0; список адресов страницами по 100 с копированием.
- MTU/MSS для IPv4/IPv6 с ручным overhead.
- Поиск longest prefix match в списке маршрутов с равными кандидатами.
- Проверка адресного условия ACL по wildcard, включая прерывистые маски.
- Пять вкладок, дневная/ночная темы с сохранением выбора.
- Ctrl+1…5 для вкладок, Ctrl+Shift+C для результата, Ctrl+Shift+T для темы.

Четыре формата MAC, регистр, исходный CLI и имя MacAddressConverter.exe сохранены.
Приложение работает offline и сохраняет только тему, без истории адресов.

### Скачивание

Рекомендуемая поставка — NetworkTools-1.1.0-windows-x64.zip: распаковать и
запустить MacAddressConverter.exe. Установка Python не требуется.
Также приложены отдельный EXE, SHA256SUMS.txt и RELEASE_VERIFICATION.json.
В ZIP сохранены инструкция и оригинальные runtime licenses.

### Проверка

Публикация допускается после unit/GUI tests и фактического запуска EXE в Windows
от стандартного пользователя, в папке с пробелами/кириллицей, с очищенным Python/Tcl
окружением. Проверяются все инструменты, clipboard, ошибки, темы и перезапуск.
Точная версия, commit, SHA-256 и фактические результаты находятся в
RELEASE_VERIFICATION.json и docs/VALIDATION_1_1_0.md.

Целевая среда — Windows 10/11 x64; стенд — Windows Server CI. Клиентские версии,
разные DPI, Defender и SmartScreen ещё требуют отдельной проверки. EXE без подписи.
MSS — расчёт фиксированных заголовков, а не измерение Path MTU; маршруты и ACL
анализируют введённые условия, без модели конфигурации устройства.
