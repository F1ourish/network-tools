# Проверка Network Tools 1.4.0

Дата: 07.10.2026. Статус: подготовлено к проверке; Windows результаты ещё не подтверждены.

Изменения: большой редактор ACL, нумерация и подсветка строк, очистка вставки,
флажки отсутствия ACL, подсказки Cisco in/out и прокрутка по необходимости.
Object-group диагностируется явно; разрешение состава групп не реализовано.

## Проверки выпуска

- Linux: Ruff check / format и все non-GUI тесты.
- Windows: полный pytest с `--require-gui`, без пропусков GUI.
- Новый GUI проверяет скрытие/появление полос, номера при прокрутке, очистку
  вставки, флажки, диагностику, синхронизацию большого окна и темы.
- Настоящий `NetworkTools.exe`: существующие проверки шести вкладок,
  Ctrl+V с очисткой ACL, открытие и закрытие большого редактора,
  сохранение изменений и оба флажка отсутствия ACL.
- Publisher проверяет точный source commit и assets того же CI run.

После финальной сборки здесь фиксируются commit, CI run, число тестов,
нативные результаты и SHA-256. К релизу прилагаются `RELEASE_VERIFICATION.json`
и `SHA256SUMS.txt`.

Целевая среда - Windows 10/11 x64. Hosted Windows Server CI не подтверждает
клиентскую приёмку, DPI 125-200% или корпоративные политики. EXE без подписи.
