**Network Tools 1.6.0** - поиск кандидатов IPv4 по ARP.

### Изменения

- Новая вкладка «Свободные IP»: сеть/IP с CIDR или маской и поле для ARP-вывода.
- Вставка удаляет строки без IPv4, команды просмотра и пробелы по краям.
  Поддерживаются вывод Cisco/Windows/Linux и простой список IP.
- Исключения `.33, .34` добавлены по умолчанию. Можно указать список через запятую
  и диапазоны `.50-.60` или `192.0.2.100-192.0.2.110`, включая границы.
  Короткая запись исключает последний октет во всей подсети, полный IPv4 - конкретный адрес.
- Дубликаты и пересечения ARP/исключений не увеличивают счётчики дважды.
  Адреса вне подсети видны отдельно; ошибочный IPv4 показывает номер строки.
- Страницы по 100 адресов и переход по номеру работают без полного перебора большой сети.
  Можно копировать страницу, весь список до 10000 IP или отчёт с текущей страницей.
- Ctrl+7 выбирает вкладку, F1 открывает инструкции и пример. Темы сохранены;
  введённые ARP и исключения не записываются на диск.

Отсутствие адреса в ARP не подтверждает, что он свободен. Перед назначением
сверить IPAM/DHCP и проверить конфликт. Приложение выполняет локальный расчёт,
не сканирует сеть и не назначает адреса.

### Обновление и проверка

Распаковать `NetworkTools-1.6.0-windows-x64.zip` и запустить `NetworkTools.exe`.
Python не требуется; настройка темы совместима с предыдущими версиями.

Linux lint/format и тесты логики, полный pytest Windows с обязательным GUI,
сборка PyInstaller и проверки настоящего EXE от стандартного пользователя.
Фактические результаты и source commit:
[`RELEASE_VERIFICATION.json`](https://github.com/F1ourish/network-tools/releases/download/v1.6.0/RELEASE_VERIFICATION.json).
Контрольные суммы:
[`SHA256SUMS.txt`](https://github.com/F1ourish/network-tools/releases/download/v1.6.0/SHA256SUMS.txt).

Целевая среда - Windows 10/11 x64; нативный стенд CI - Windows Server.
EXE без цифровой подписи. Клиентская приёмка и DPI проверяются отдельно.
