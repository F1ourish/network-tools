**Network Tools 1.2.0** — генератор паролей и справка для всех вкладок.

### Добавлено

- Генерация паролей через системный криптографический источник `secrets`.
- Длина 8–128 (default 20); группы a–z/A–Z/цифры/спецсимволы обязательны при выборе;
  ручной набор спецсимволов и исключение похожих `0 O 1 I l |`.
- Равномерная генерация, оценка энтропии пространства; при ошибке CSPRNG генерация прекращается.
- Скрытие/показ, Copy/Очистить; новый пароль создаётся только по нажатию кнопки.
- Условная очистка собственного clipboard через 30 с (включена по умолчанию) и при закрытии;
  замещающий текст не удаляется. Пароли не сохраняются и не отправляются по сети.
- Контекстная справка для MAC, IPv4, MTU/MSS, маршрутов, ACL и паролей: F1 или «Помощь».
  В справке есть шаги, примеры и границы применения, включая LPM и wildcard/permit/deny.
- Ctrl+6 выбирает генератор; Ctrl+Shift+C копирует результат. Дневная/ночная темы сохранены.

### Скачать

Рекомендуется `NetworkTools-1.2.0-windows-x64.zip`: распаковать и запустить
`MacAddressConverter.exe`. Python устанавливать не требуется. Приложены отдельный
EXE, `SHA256SUMS.txt` и `RELEASE_VERIFICATION.json` с точным commit и результатами CI.

### Проверка

Релиз создаётся только после unit/GUI-тестов без пропусков и фактического запуска EXE
на Windows от стандартного пользователя. Проверяются прежние инструменты, генератор,
справка, ошибки, clipboard, темы и перезапуск. Фактические результаты и SHA-256 —
в приложенном `RELEASE_VERIFICATION.json`; процедура — `docs/BUILD_AND_RELEASE.md`.

Целевая среда Windows 10/11 x64; автоматический стенд Windows Server.
Клиентские версии, DPI 125–200%, Defender/SmartScreen и корпоративные политики
остаются отдельным acceptance. EXE без цифровой подписи. Автоочистка не удаляет
историю/синхронизацию буфера Windows; надёжное затирание памяти Python не гарантируется.
