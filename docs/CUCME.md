# CUCME: поиск и свободные ресурсы

Версия документа: 1.2; дата: 15.10.2026. Область: локальный анализ SCCP-конфигурации Cisco CME.

Одна вкладка хранит один конфиг в памяти и предоставляет два режима.
Связь определяется по button: номер секции аппарата и номер секции DN не обязаны совпадать.
Программа не подключается к Cisco, не применяет конфигурацию и не проверяет регистрацию.

## Поиск и проверка

| Ввод | Сопоставление |
| --- | --- |
| Номер ephone | Точный номер секции ephone, затем все её кнопки и DN |
| Номер ephone-dn | Точный номер секции DN и все ссылающиеся аппараты/кнопки |
| Телефон | Точное number/secondary либо цифровой токен description DN |
| Имя / label | Части слов одновременно в name, label и description аппарата; без учёта регистра |
| Любое поле | Числовой запрос сопоставляется с точными номерами секций/телефонами; текстовый также ищется по имени/описанию |

Синтетический пример:

```text
ephone-dn 85 dual-line
 number 31085
 description 31085
 name Example Alex
 label Example A.
!
ephone 585
 description Example Alex Office
 mac-address 0011.2233.4455
 type 7942
 button 1:85
!
```

Поиск ephone 585 показывает аппарат, button 1:85 и DN 85.
Телефон 31085, часть label `Example A.` и описание `Office` находят ту же связь.
Поле number задаёт назначенный телефонный номер, secondary - дополнительный.
Поле description - произвольное описание, которое может содержать телефон.
Поля независимы: несовпадение не исправляется автоматически и само по себе не означает ошибку.
Отчёт сохраняет оба значения, name/label, type, MAC и физические номера строк.
Повторяющийся телефон может соответствовать нескольким DN/аппаратам: показаны все.
Аппарат без button и DN без привязки также находятся по номеру секции.

## Рабочая область и результат

Вкладка заполняет высоту окна. Вертикальный разделитель меняет доли редактора
и результата, ширина следует за окном. Рядом с каждой областью есть ↗:
ввод открывается в большом редактируемом окне, результат - в окне просмотра.
Изменения текста синхронизируются между редакторами. При ошибке старый результат
очищается в обоих представлениях; исходный конфиг остаётся.

F4 переводит фокус в конфиг, F6 - в результат. Ctrl+Enter разворачивает область,
Escape возвращает во вкладку. Ctrl+Shift+C копирует отчёт страницы.

Переадресации показаны в карточке DN: call-forward all/busy/noan/night-service,
их значения и параметры timeout/primary/secondary/dialplan-pattern.
Дополнительные call-forward настройки сохранены с подписью. Номера назначения
переадресации не считаются собственными номерами DN при поиске свободных телефонов.
Переадресации из предоставленного ephone-dn-template наследуются; прямые команды
DN имеют приоритет, no call-forward отменяет соответствующие значения.
Для отсутствующего шаблона сведения явно помечены как неполные.
Остальные поля шаблонов не разворачиваются. Фактическая работа переадресации,
расписание night-service и доступность назначения по сети не проверяются.

## Парная таблица номеров секций

Ресурс «ephone / ephone-dn» сравнивает обе независимые области номеров в каждой
строке диапазона. Столбцы: «Номер», «ephone», «ephone-dn». Диапазон включительный.

| Состояние | ephone | ephone-dn |
| --- | --- | --- |
| ✓ | Секция не создана в снимке | Нет секции и ссылки button, номер в max-dn |
| ✗ | Секция существует, в том числе пустая/FREE | Секция существует, есть ссылка button либо номер выше max-dn |

Все номера диапазона показаны по 100 строк; частично доступные пары сохранены.
Одинаковый номер в строке не устанавливает привязку: её определяет button.
SIP-разделы и шаблоны не создают скрытые SCCP секции и не блокируют эту таблицу.
Наличие явного ephone/ephone-dn или ссылки на DN сохраняет занятость номера секции.
max-ephones показан отдельно как количество аппаратов и остаток ёмкости;
отсутствующая секция сама по себе не подтверждает возможность создать ещё аппарат.

Ctrl+A/C в таблице копирует строки с заголовком в TSV. «Все строки» копирует
до 10000 строк. Большой диапазон до 1000000 номеров не перечисляется целиком:
генерируется только текущая страница. Номера секций сравниваются как целые числа.

## Телефонные номера

Ресурс «Телефонные номера» сохраняет поиск по number, secondary и числовым
токенам description DN. Плюс перед номером также резервирует числовое значение.
Call-forward и speed-dial не считаются собственными номерами DN.
Буквенные номера сохраняются для поиска, в числовой диапазон не попадают.
Ведущие нули сохраняются при одинаковой длине границ. Список - до 10000 номеров.

SIP voice register и прочие поля шаблонов не моделируются полностью.
При их наличии общий список свободных телефонов блокируется, чтобы не выдать
неучтённые номера как свободные. Это ограничение приложения, а не ошибка конфига.
Выбрать «ephone / ephone-dn» для проверки номеров секций SCCP. Подробности и
найденные заголовки с номерами строк находятся в отдельном окне замечаний.

## Замечания и ошибки

«Замечания» / F8 открывает отдельное окно всех замечаний по конфигу, ограничений
выбранной операции и ошибок разбора. В самом результате они не дублируются.
Показаны конкретные поля, значения и физические строки. Для синтаксической ошибки
приведены текст строки и действие для исправления, строка выделена в обоих редакторах.
После исправления или смены режима окно обновляется; очистка удаляет старые замечания.
Конфигурация сохраняется при ошибке. Число замечаний видно на кнопке.

## Синтаксис и ограничения

Поддерживаются ephone-dn single/dual/octo-line, number с secondary/no-reg,
name/label/description, ephone description/type/mac-address и несколько button.
Разделители :/b/c/f/m/o/s/w сохраняются. o/c связывают одну кнопку с несколькими DN.
x ссылается на overlay-кнопку o этого аппарата; номер кнопки не принимается за номер секции DN.
Отсутствующая исходная кнопка, цикл или неверный синтаксис дают ошибку строки.
Дублирующиеся секции/кнопки отклоняются, общие номера и общие DN разрешены.

Прочие команды running-config остаются в редакторе. Они не моделируются как
полная конфигурация телефонии. SIP voice register и шаблоны не разворачиваются:
SIP/шаблоны блокируют только общий поиск свободных телефонов,
поиск прямых SCCP-связей остаётся доступным. Точки в number блокируют поиск
свободных телефонов вместо неявного пропуска шаблона. Другие резервы, например
dial-peer и dial-plan, не учитываются. «Не найден» во фрагменте не доказывает свободу.
Перед назначением требуется полный актуальный конфиг и проверка ограничений платформы.

До 30000 строк/2 МБ текста, до 100000 связей. Вывод страницами по 10 связей
или 100 свободных номеров; «Все номера» - до 10000 значений.
Большие числовые диапазоны хранятся интервалами, без перебора всех номеров.

## Сохранение и очистка

Поиск, смена режима, вкладки, темы, диапазона и ошибка не изменяют конфиг.
Редактирование очищает устаревший результат и откладывает новый разбор на 180 мс.
Кнопка «Вставить конфиг» явно заменяет текст; Ctrl+V/Shift+Insert/меню вставляют по курсору.
«Очистить конфиг» удаляет текст, модель, результат и undo редактора.
Закрытие завершает сессию. На диск записывается только тема.
В публичных примерах и тестах используются синтетические данные.
