## Проверенные изменения

CUCME проверяет независимые ID ephone/DN и связи button, все виды поиска,
description/name/label, несколько кнопок и общие DN. Пустые секции и отсутствующие
DN из button не предлагаются как свободные ID. Number и description сохраняются
отдельно; одинаковые номера и описания возвращают все связи.
Тип и MAC берутся из соответствующего ephone, а не из секции с похожим ID.

Разбор проверяет overlay o/c и x со ссылкой на кнопку, ошибочные/дублирующиеся
секции, номера физических строк, max-dn и независимость диапазона ephone от max-ephones.
Малые свободные диапазоны сверены с независимым полным перебором; большие
используют компактные интервалы и переход на последнюю страницу.
Ведущие нули и плюс, secondary, числовые токены description и явные ограничения
SIP/шаблонов проверены. Прежние тесты инструментов сохранены.

GUI подтверждает точное сохранение текста и переиспользование модели при запросах,
смене режима, вкладки и темы. Вставка сохраняет отступы и строки. Ошибка ввода
очищает старый результат, не конфиг; исправление восстанавливает поиск.
Явная очистка удаляет конфиг/undo. Проверены readonly отчёт, копирование, страницы,
Ctrl+8/Ctrl+L/Ctrl+Shift+C и F1. На диск сохраняется только тема.

Настоящий EXE проверен клавиатурой и системным clipboard: синтетическая связь
ephone 585 -> button 1:85 -> DN 85; description 32085 и number 31085 показаны
раздельно, type 7942 и тестовый MAC сохранены. Поиск по DN, телефону описания,
частям name/label и описания аппарата возвращает связь.
В диапазоне DN 1-100 свободны 98 ID: пустой DN 30 и назначенный DN 85 исключены.
Проверены ephone 584/586 вокруг занятого 585, свободные телефонные номера,
сохранение точного конфига при ошибке диапазона, явная очистка и повторная вставка.
После перезапуска конфиг/запрос пусты. Снимки опубликованного EXE просмотрены;
источник: [описание снимков](screenshots/README.md).

Publisher сверил source commit и assets одного CI run. Размеры и SHA-256
опубликованных файлов совпадают со скачанными artifacts. EXE и отчёт внутри ZIP
совпадают с отдельными assets; все контрольные суммы проверены.
