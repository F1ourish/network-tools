# Проверка Network Tools 1.7.0

Дата: 15.10.2026. Статус: ожидается полная проверка Windows и публикация.

- Локально успешны Ruff check/format и 551 non-GUI test.
- Результаты Windows GUI/EXE и контрольные суммы фиксируются после CI.

Тесты CUCME охватывают ID/телефоны/имена, description/name/label, несколько
button и общие DN, overlay/x, пустые секции, отсутствующие DN, неверный синтаксис
и физические строки, границы/лимиты, max-dn и независимость ID от max-ephones.
Свободные интервалы сверяются с независимым полным перебором малых диапазонов.
Большие диапазоны и переходы проверяются без полного перечисления.

Проверки GUI охватывают сохранение точного конфига, все способы вставки,
переиспользование модели, смену режима/запроса/темы/вкладки, ошибки, очистку,
undo, readonly отчёт, копирование, Ctrl+8, F1 и страницы.
Прежние проверки инструментов сохранены. В публичных тестах только синтетические данные.
