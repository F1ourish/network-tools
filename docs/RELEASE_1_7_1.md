**Network Tools 1.7.1** - читаемый отчёт CUCME и отдельное большое окно.

### Изменения

- «Развернуть отчёт» или Ctrl+Enter открывает отдельное окно на весь экран.
  Доступны копирование, страницы, изменение размера и возврат по Escape.
  Новый запрос обновляет оба окна; ошибка и очистка удаляют устаревший результат.
- Вместо «ID занят» явно указано, какая секция ephone/ephone-dn существует в конфигурации.
  Замечания содержат description, номер строки и конкретные незаполненные поля.
  Описание FREE видно в отчёте; созданная секция исключается из свободных номеров секций.
- number подписан как назначенный телефонный номер, description - как описание.
  При различии прямо в замечании приведены оба значения и назначение полей.
- Русские подписи, читаемый шрифт и отдельные строки в карточках.
  Замечания по всей конфигурации разделены на пронумерованные абзацы.

### Обновление и проверка

Распаковать `NetworkTools-1.7.1-windows-x64.zip` и запустить `NetworkTools.exe`.
Python не требуется. Тема совместима с предыдущими версиями.

Проверки Linux lint/format, полный Windows pytest с обязательным GUI,
сборка PyInstaller и нативные проверки готового EXE от стандартного пользователя.
Фактические результаты и source commit:
[`RELEASE_VERIFICATION.json`](https://github.com/F1ourish/network-tools/releases/download/v1.7.1/RELEASE_VERIFICATION.json).
Контрольные суммы:
[`SHA256SUMS.txt`](https://github.com/F1ourish/network-tools/releases/download/v1.7.1/SHA256SUMS.txt).

Целевая среда - Windows 10/11 x64; нативный стенд CI - Windows Server.
Анализируется предоставленный конфиг. Подробности: [CUCME](https://github.com/F1ourish/network-tools/blob/main/docs/CUCME.md).
