## Проверенные изменения

Расчёты ARP проверяют вывод Cisco/Windows/Linux, списки IP, дубликаты,
внеподсетные адреса, Incomplete/FAILED и физические строки ошибочного IPv4.
Вставка удаляет строки без IP и команды просмотра, сохраняет ошибочные IP
для диагностики и обрезает крайние пробелы.

Проверены .33/.34 по умолчанию, списки через запятую, короткие и полные диапазоны,
границы диапазонов и пересечения с ARP. Короткие октеты повторяются внутри /23,
полные IPv4 исключают конкретный адрес; пересечения считаются один раз.
Малые сети сверены с независимым полным перебором. /31-/32, пустые результаты,
большая /1, переходы между страницами и лимиты копирования проверены отдельно.

GUI-тесты охватывают все способы вставки, readonly список, номера строк,
очистку старого результата при изменении каждого поля, восстановление после
ошибки, CIDR/маску, копирование страницы/списка/отчёта, Ctrl+7, F1 и темы.
Настройки сохраняют только тему. Прежние проверки инструментов сохранены.

Настоящий EXE проверен через клавиатуру и Windows clipboard: полный ARP,
250 кандидатов для /24 с ARP .1/.2 и исключениями .33/.34; диапазоны дают
228 кандидатов, переход на последнюю страницу и копирование 28 IP.
Ошибка исключений очищает прежний вывод; исправление восстанавливает расчёт.
/1 рассчитывается без полного перебора. После перезапуска ARP пуст,
исключения возвращаются к .33, .34. Снимки интерфейса просмотрены;
источник снимков: [описание](screenshots/README.md).

Publisher сверил source commit и assets одного CI run. Размеры и SHA-256
опубликованных файлов совпадают со скачанными artifacts. EXE и отчёт внутри
ZIP совпадают с отдельными assets; все контрольные суммы проверены.
