# Проверка Network Tools 1.6.0

Дата: 09.10.2026. Статус: ожидается полная проверка Windows и публикация.

- Локальный Ruff check и 477 non-GUI tests успешны.
- Windows pytest с обязательным GUI, настоящий EXE и hashes фиксируются после CI.

Проверки охватывают очистку ARP, дубликаты, IPv4 вне подсети, строки с ошибками,
короткие/полные исключения и их пересечения, /31-/32, большие сети, страницы,
копирование и очистку устаревшего результата. Случайные небольшие сети сверяются
с независимым полным перебором; большие сети используют компактные интервалы.

Нативный стенд проверяет ввод из Windows clipboard, Ctrl+7/Ctrl+L, копирование,
диапазоны, переход на последнюю страницу, восстановление после ошибки и F1.
Проверки прежних инструментов сохранены.
