# Архитектура Network Tools 1.4.0

Версия документа: 3.0; дата: 07.10.2026; контур: desktop utility.

Приложение выполняет локальные расчёты в независимых модулях. GUI управляет
вводом, темой и clipboard; CLI использует прежнее MAC API. Сеть и запуск
системных команд в runtime приложения отсутствуют.

| Компонент | Ответственность |
| --- | --- |
| mac.py | Нормализация и 4 формата MAC-48 |
| network.py | IPv4, проверка маски, lazy host pages, MSS, LPM и wildcard |
| settings.py | Atomic сохранение только темы; fallback при повреждении |
| gui.py | Шесть вкладок с прокруткой, live validation, readonly output, copy и shortcuts |
| main.py / __main__.py | Tk root и event loop |
| cli.py | MAC CLI, exit codes 0/2; сохранён без изменения поведения |
| __init__.py | Единственная версия для package metadata, EXE и release |
| mac-converter.spec | Onefile/windowed, ресурсы UI, notices, asInvoker, version resource |
| build_windows.py | Обязательные GUI tests, PyInstaller, EXE smoke, ZIP и hashes |
| smoke_windows.py / windows_process.py | Внешний Win32 стенд и запуск standard-user; не входят в EXE |
| publish_release.py | Проверка SHA/version/commit/passed и публикация CI assets без overwrite |

## Расчёты и обработка ошибок

IPv4 адрес и маска проверяются явно: dotted wildcard не интерпретируется как
netmask. CIDR suffix синхронизируется с маской в GUI; обычный режим нормализует
IP к сети, strict mode требует network address. `/31`, `/32`, `/0` имеют
отдельные правила отображения. Страницы хостов вычисляются integer offsets;
список всей подсети никогда не создаётся. Окно хостов хранит снимок расчёта.

MSS вычитает заданный вручную overhead и фиксированные заголовки. LPM сортирует
только совпавшие введённые CIDR по убыванию длины, сохраняя все равные кандидаты.
Wildcard выполняет `(base XOR ip) AND (NOT wildcard)` в 32 битах.
Это вычисления над данными, а не модель packet forwarding устройства.

Ошибка ввода очищает результаты затронутого инструмента и отключает copy.
Неожиданная callback error очищает вычисленные результаты и предлагает
перезапуск без traceback и записи введённых данных. Ошибка clipboard выводит
сообщение о повторном Copy. Ошибка сохранения темы не мешает её применению.

## Runtime и данные

GUI зависит от ttkbootstrap 2.2.3 и Pillow 12.3.0; версии закреплены.
Windows EXE включает Python 3.12.10, Tcl/Tk, UI ресурсы и оригинальные notices.
PyInstaller временно распаковывает runtime в пользовательский TEMP. Smoke
проверяет DLL из bundle и запуск без Python/Tcl environment от medium token.
Физически чистая Windows 10/11 и разные DPI проверяются отдельно.

Сохраняется только `%APPDATA%\MacAddressConverter\settings.json` с ключом theme.
Запись использует временный файл и os.replace. Ограничение чтения 8 KiB;
неизвестная/повреждённая тема даёт day. Адреса, маршруты и история не сохраняются.
CLI и pure calculations не обращаются к настройкам или GUI.

## Расширение 1.2.0

passwords.py содержит независимую от GUI политику, CSPRNG-генерацию с rejection sampling,
проверку групп и inclusion-exclusion подсчёт числа допустимых строк. secrets.choice
получает символы из дедуплицированного объединения непересекающихся ASCII-групп.
Не подходит обязательная группа - вся строка отбрасывается: валидные строки равновероятны.
Четыре группы и минимальная длина 8 ограничивают стоимость обычных сценариев.
Отказ источника случайности не включает fallback. Политика не сохраняется.

help_content.py - неизменяемые тексты по индексу вкладки. GUI открывает modeless
Toplevel; справка следует за активной вкладкой. generate_password вызывается только
по действию пользователя, а изменение политики сбрасывает прежний секрет.

Clipboard timer хранит только последнее скопированное значение до очистки/перекопирования.
Перед удалением сравнивается содержимое буфера; чужой новый текст сохраняется.
Явная очистка и уничтожение основного окна отменяют callback и выполняют такую же попытку.
Python/Tk значения в памяти не являются защищённым хранилищем и не гарантируют zeroization.

На Windows очистка выполняется через OpenClipboard/GetClipboardData/EmptyClipboard.
Сравнение и удаление идут под одной блокировкой буфера; чужая замена не удаляется.
При занятом буфере timer выполняет до трёх повторов с интервалом 1 с. При закрытии -
одна попытка до уничтожения Tk-окна. Неудача отмечается в статусе.
Источник API: https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-emptyclipboard

## Расширение 1.3.0

mtu.py отделяет IP MTU, Ethernet payload и кадр с FCS. PPPoE вычитается только из
L2 budget; VLAN учитывается в L2. Профили создают состав expansion; двоичный поиск
находит наибольший внутренний IP packet, помещающийся в внешний budget.
Для ESP учитывается фактическая длина зашифрованной части, trailer и alignment;
MSS вычитает фиксированные внутренние IP/TCP заголовки. Параметры профиля явные.

acl.py строго разбирает одну Cisco IOS IPv4 ACL на поле, сохраняет исходную строку
и sequence number, сортирует последовательность и применяет первое совпадение.
Отсутствующий нужный порт даёт indeterminate до более поздних правил. Оба списка
валидируются целиком; неподдерживаемые условия никогда не игнорируются.
Ответ переставляет адреса/порты, для TCP ACK=1. Это не stateful connection tracking.
GUI откладывает разбор изменённого списка на 180 мс и сразу очищает старый результат.

acl_editor.py содержит нумерованный Text и AutoScrollbar, скрывающийся при полном
видимом диапазоне. Большое Toplevel-окно и основной редактор синхронизируются;
закрытие сохраняет изменения. AclSyntaxError передаёт физическую строку, правило,
sequence number и сторону запроса/ответа для подсветки. Нормализация вставки
обрезает пробелы строк и Cisco counters без удаления пустых строк.
Два явных флажка отсутствия ACL пропускают разбор сохранённого текста только
в отмеченной стороне. Выбор интерфейса меняет подсказки in/out, сохраняя
семантику запроса и ответа. Разрешение object-group в этой версии не реализовано.

Все Entry/Text имеют общую вставку, выделение и контекстное меню. Кнопка заменяет
содержимое; обычная вставка учитывает курсор/выделение. CIDR применяется атомарно.
Win32 virtual-key codes сохраняют Ctrl-shortcuts независимо от раскладки.
Копирование выделения пароля использует ту же условную автоочистку, что Copy.

Источники профилей и границы модели: [MTU и ACL](MTU_AND_ACL.md).
