**Network Tools 1.5.1** - исправления генератора паролей.

### Изменения

- «Сгенерировать» сохраняет состояние флажка «Показать»: новые пароли остаются
  видимыми либо скрытыми согласно выбранному состоянию.
- «Сбросить» рядом с полем «Допустимые спецсимволы» возвращает стандартный набор.
  Кнопка доступна, когда список отличается от исходного, включая пустой или ошибочный ввод.
- Восстановление списка очищает устаревший пароль и заново проверяет параметры.
  Длина, выбранные группы и исключение похожих символов сохраняют свои значения.
- Контекстная справка F1, инструкции и проверки генератора обновлены.

### Обновление

Распаковать `NetworkTools-1.5.1-windows-x64.zip` и запустить `NetworkTools.exe`.
Python не требуется. Настройка темы совместима с предыдущими версиями.
При изменении параметров, очистке результата и переключении вкладки пароль скрывается,
как в предыдущей версии. Показ сохраняется при повторной генерации.

### Проверка

Linux lint/format и тесты логики, полный pytest Windows с обязательным GUI,
сборка PyInstaller и проверки настоящего EXE от стандартного пользователя.

[`RELEASE_VERIFICATION.json`](https://github.com/F1ourish/network-tools/releases/download/v1.5.1/RELEASE_VERIFICATION.json).
Контрольные суммы:

Целевая среда - Windows 10/11 x64; нативный стенд CI - Windows Server.
EXE без цифровой подписи. Клиентская приёмка и DPI проверяются отдельно.
