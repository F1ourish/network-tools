**Network Tools 1.4.0** - удобный редактор Cisco ACL.

### Добавлено и исправлено

- «Развернуть» и Ctrl+Enter открывают большой редактор каждого списка ACL.
  Изменения синхронизируются с основной вкладкой; Escape закрывает окно и сохраняет текст.
  Ctrl+L в большом редакторе переводит фокус в поле и выделяет весь список.
- Номера строк слева, подсветка и переход к ошибке. Сообщение показывает направление,
  физическую строку, sequence number и проблемное правило.
- Полосы прокрутки появляются только при переполнении текста или вкладки.
- Вставка кнопкой, Ctrl+V, Shift+Insert и меню удаляет пробелы по краям строк
  и счётчики `(N match)` / `(N matches)`. Пустые строки сохраняют нумерацию.
- Флажок отсутствия ACL для каждого направления сохраняет текст и пропускает этот фильтр.
- Подсказки `ip access-group <name> in/out` и направление пакета учитывают
  выбранный интерфейс со стороны источника или назначения.
- Ошибка `object-group` объясняет необходимость состава группы и показывает
  `show object-group <name>`. Разбор таких групп пока не реализован;
  их адреса нужно развернуть в отдельные правила.
- Контекстная справка и инструкции обновлены.

### Обновление

Распаковать `NetworkTools-1.4.0-windows-x64.zip` и запустить `NetworkTools.exe`.
Python не требуется. Имя EXE введено в 1.3.1, настройка темы совместима.
Два поля ACL проверяют запрос и ответ; для ответа IP и порты меняются местами.
Пустая ACL ответа без флажка означает «ответ не проверен».

### Проверка

Перед публикацией выполняются Linux lint/format и тесты логики, полный pytest
на Windows с обязательным GUI, сборка PyInstaller и проверки настоящего EXE
от стандартного пользователя, включая большие редакторы и флажки ACL.
