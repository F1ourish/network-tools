**Network Tools 1.8.2** - списки портов и направления ACL интерфейса.

### Исправления

- Поддерживаются от 1 до 10 портов после `eq` и `neq`, независимо для источника и назначения. Можно смешивать имена сервисов и номера.
- `eq www 443` принимает порт 80 или 443; `eq 22 3389` принимает оба номера; `neq 22 3389` исключает каждый из них. Одиночные условия и `range` сохраняют свой смысл.
- Поля ACL постоянно соответствуют командам Cisco: **in слева, out справа**. Выбор стороны интерфейса определяет фактическую проверку запроса и ответа без перестановки текста.
- Для интерфейса со стороны назначения запрос проверяется по `out`, ответ по `in`; со стороны источника наоборот.
- Отчёт показывает сторону интерфейса, имя списка, направление и первое сработавшее правило. Ошибка подсвечивает нужное поле in/out и его большой редактор.
- Флажки отсутствия остаются при своих списках. Пример HTTPS возвращает согласованные настройки. Справка и инструкции обновлены.

### Обновление

Распаковать `NetworkTools-1.8.2-windows-x64.zip` и запустить `NetworkTools.exe`.
Python не требуется. Для ACL вставить список из `ip access-group <name> in` в поле **ACL in**,
список `out` в **ACL out**, затем выбрать сторону интерфейса относительно запроса.

Проверка включает логику, настоящий GUI Windows, PyInstaller и запуск готового EXE
от стандартного пользователя. Публичные примеры и снимки используют тестовые адреса.
Результаты: [`RELEASE_VERIFICATION.json`](https://github.com/F1ourish/network-tools/releases/download/v1.8.2/RELEASE_VERIFICATION.json).
Хеши: [`SHA256SUMS.txt`](https://github.com/F1ourish/network-tools/releases/download/v1.8.2/SHA256SUMS.txt).

Целевая среда - Windows 10/11 x64; нативный стенд - Windows Server CI.
