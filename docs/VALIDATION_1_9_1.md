## MAC и связи CUCME

Проверяется поиск по ephone, DN, телефону и имени, несколько аппаратов на одном DN,
несовпадение номеров секций, пустой/no mac-address, аппарат без button и сохранение
MAC в четырёх колонках TSV. MAC берётся только у фактического ephone.

GUI проверяет отдельную строку карточки и копирование, видимость колонки MAC,
совпадение обычного/развёрнутого окна, выбранных строк и полного TSV.
Замена конфигурации удаляет прежний MAC из обоих результатов.
Native EXE проверяет карточку, обе реальные таблицы и копирование MAC.

Публичные примеры и снимки используют синтетические конфигурации и адреса.
Целевая среда - Windows 10/11 x64; фактический стенд - Windows Server CI.
Клиентские Windows, DPI 125-200%, Wine и macOS отдельно не проверялись.
