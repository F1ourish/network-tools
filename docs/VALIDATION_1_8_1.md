# Проверка Network Tools 1.8.1

Сборка запускается после проверки исходников. Финальные числа тестов, commit,
среда Windows, хеш EXE и нативные действия фиксируются в
[RELEASE_VERIFICATION.json](https://github.com/F1ourish/network-tools/releases/download/v1.8.1/RELEASE_VERIFICATION.json).
Релиз публикуется только после успешного полного pytest с обязательным GUI,
PyInstaller и проверки готового EXE от стандартного пользователя.

GUI-проверки охватывают заполнение свободного места, перетаскивание краёв и углов,
изменение обеих областей CUCME, ограничение размеров, общие кнопки,
синхронизацию больших редакторов и результатов, readonly, ошибки и страницы.
Нативная проверка EXE использует реальные действия мышью и клавиатурой.
Фактические результаты добавляются по завершении сборки.
