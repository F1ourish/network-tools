# Проверка Network Tools

Версия: 2.0; дата: 06.10.2026; контур: native Windows CI / отдельный client acceptance.

Подтверждённые результаты и hashes фиксируются в VALIDATION_1_1_0.md.
Server CI, source GUI tests и client acceptance имеют разную область покрытия.
GUI skips не считаются подтверждением работы интерфейса.

Кандидат 1.1.0: 223 pytest tests (186 без GUI, 37 с GUI), без ошибок и пропусков;
28 actual-EXE checks. Результат конкретной опубликованной сборки записывается
в приложенный RELEASE_VERIFICATION.json, включая commit и SHA-256 EXE.

## Автоматические проверки

- MAC: ASCII/длина/разделители, 4 формата, регистр, CLI, clipboard и callbacks.
- IPv4: все 33 маски и границы адресов, invalid masks/CIDR, host normalization,
  strict network, /31, /32, /0, первая/последняя страница больших сетей.
- MSS: fixed headers IPv4/IPv6, manual overhead и ошибки MTU/чисел.
- LPM: host/default route, равные кандидаты, порядок, комментарии, отсутствие
  совпадения, невыравненный CIDR, лимит списка.
- ACL: non-contiguous wildcard, полная/нулевая маска, random per-octet cross-check.
- Persistence: corrupt/oversized settings, invalid theme, atomic replace failure.
- GUI: defaults, live updates, CIDR paste/typing, clear/recovery, readonly/copy,
  host pages/snapshot, темы с сохранением ввода, reload и shortcuts.
- Готовый EXE: PE x64/windowed/asInvoker/version, bundled notices/fonts/DLL,
  medium non-admin token, изолированный каталог, все инструменты, themes/restart.

```powershell
.\.venv\Scripts\python.exe -m pytest -q --require-gui
.\.venv\Scripts\python.exe scripts/build_windows.py
```

Второй скрипт также запускает первый этап и затем готовый EXE. Не подменять
EXE smoke тестом исходного Python. Результаты и PNG относятся к проверенному hash.

## Отдельная клиентская проверка

Зафиксировать SHA-256, Windows edition/build, локаль, DPI, тип учётной записи,
наличие Python и путь EXE. Использовать опубликованный asset без пересборки.

| Действие | Ожидаемый результат |
| --- | --- |
| Стандартный пользователь, Windows 10/11 x64 без Python | Запуск EXE без console/elevation, нет missing runtime |
| Папка с пробелами/кириллицей | Все вкладки, clipboard и restart работают |
| 100/125/150/200% и уменьшение окна | Поля доступны, длинные результаты копируются, вертикальная прокрутка работает |
| Дневная/ночная темы, фокус и Tab | Читаемые текст/контраст, ввод сохраняется, focus виден |
| IPv4 192.168.1.42/24 + strict | Normal: сеть .0; strict: ошибка host bits; stale copy отсутствует |
| IPv4 /31, /32, /0 и /8 host list | Корректные особые случаи; страницы не тормозят от размера блока |
| MAC 0011.2233.aabb, все форматы/регистр | Значения совпадают с README |
| MTU 1500 IPv4/IPv6 | MSS 1460/1440, overhead отдельно |
| Маршруты /0,/16,/24 с двумя /24 | Все matching routes; два равных LPM кандидата |
| Wildcard 0.0.255.254, test .2/.3 | Совпадение / несовпадение |
| Ошибка и восстановление каждого ввода | Старый результат очищен, copy disabled, затем корректный расчёт |
| Перезапуск | Только тема сохранена; все поля имеют defaults |
| Defender/SmartScreen / корпоративные политики | Зафиксировать actual поведение unsigned EXE |

Не отмечать client/DPI/security-policy пункты passed без фактической проверки.
Для проблем приложить среду, hash, шаги и screenshot с тестовыми адресами.

## Приёмка 1.3.0

- Вставить MAC/IP кнопкой, Ctrl+V, Shift+Insert и через контекстное меню.
  CIDR должен обновлять адрес и префикс вместе; readonly-результаты не меняются.
- Проверить русскую/английскую раскладки, вырезать/копировать выделение,
  многострочные списки маршрутов и ACL, ошибку при многострочной вставке в Entry.
- IP MTU 1500 + dot1q: IP MTU 1500, кадр 1522. Payload 1500 + PPPoE: IP MTU 1492.
  Известный IP MTU 1492 + PPPoE не уменьшается повторно.
- GRE/IPv4 при внешнем MTU 1500: внутренний 1476, MSS 1436.
  WireGuard/IPv4: 1440/1400; VXLAN/IPv4 без внутреннего VLAN: 1450/1410.
- Проверить ESP tunnel/transport, cipher/NAT-T/padding, OpenVPN V1/V2 TUN/TAP,
  L2TP Length/Sequence/PPP; состав overhead и копируемое пояснение.
- ACL HTTPS пример разрешает запрос/ответ; deny в любой стороне блокирует обмен.
  Проверить перестановку обоих IP/портов, sequence order, implicit deny,
  пустую ответную ACL и неизвестный порт источника.
- Object-group/time-range/fragments должны давать ошибку и очищать результат.
  Изменение многострочной ACL сразу отключает копирование старого заключения.
- Проверить длинные ACL, горизонтальную/вертикальную прокрутку, небольшое окно,
  темы и F1 справку обеих новых моделей. Старый wildcard находится в дополнительном блоке.

## Приёмка 1.4.0

- Короткий список без переполнения не имеет полос прокрутки; длинный/широкий список
  показывает нужную полосу. После очистки полосы скрываются. Проверить изменение размера.
- Номера слева соответствуют физическим строкам, включая пустые. Прокрутить до конца.
- «Развернуть» и Ctrl+Enter открывают большой редактор каждого направления;
  изменения синхронизируются в обе стороны, Escape/закрытие сохраняет текст.
  Пример и очистка из главного окна также обновляют открытый редактор.
- Кнопка, Ctrl+V, Shift+Insert и меню вставки убирают пробелы по краям строк и
  `(N match)` / `(N matches)`. Пустые строки остаются. Маршруты сохраняют исходный текст.
- Ошибка показывает направление, физическую строку, sequence и правило;
  нужная строка подсвечена и видна. После исправления подсветка исчезает.
- Object-group сообщает название и команду получения состава, не превращается
  в ошибку IPv4 и не пропускается молча. Time-range по-прежнему останавливает проверку.
- Флажок отсутствия ACL оставляет текст и пропускает разбор только этой стороны.
  Снятие возвращает прежнюю проверку, включая deny или ошибку. Deny другой стороны действует.
- Выбор стороны интерфейса меняет подсказки ip access-group in/out:
  со стороны источника запрос in / ответ out; со стороны назначения запрос out / ответ in.
- Проверить Tab/Shift+Tab, тёмную/светлую темы и восстановление после закрытия редактора.
- Настоящий EXE должен проходить вставку, большое окно и оба флажка на Windows.
