**Network Tools 1.8.0** - новая рабочая область CUCME.

### Изменения

- Растягиваемые ввод и результат с разделителем; содержимое заполняет размер окна.
- Кнопка ↗ рядом с каждой областью. Большой редактор конфигурации поддерживает изменения и синхронизацию.
- Таблица «Номер / ephone / ephone-dn»: независимые ✓/✗ статусы, частично доступные пары, страницы и копирование TSV.
- SIP/шаблоны больше не блокируют поиск номеров секций SCCP. Ограничение общего поиска телефонов объясняет причину, строки и доступный режим.
- В карточке показаны настроенные переадресации, параметры и DN-template. Прямые настройки DN имеют приоритет; отсутствующий шаблон явно указан.
- Ошибки и замечания вынесены из результата в отдельное окно с указанием строк и способа исправления.
- Читаемые заголовки карточек; F4 - конфиг, F6 - результат, F8 - замечания, Ctrl+Enter - разворачивание, Escape - возврат.

### Обновление и проверка

Распаковать `NetworkTools-1.8.0-windows-x64.zip` и запустить `NetworkTools.exe`.
Python не требуется. Введённый конфиг не сохраняется на диск; тема совместима.

Linux Ruff/тесты логики, полный Windows pytest с обязательным GUI,
PyInstaller и проверки настоящего EXE от стандартного пользователя.
Результаты: [`RELEASE_VERIFICATION.json`](https://github.com/F1ourish/network-tools/releases/download/v1.8.0/RELEASE_VERIFICATION.json).
Хеши: [`SHA256SUMS.txt`](https://github.com/F1ourish/network-tools/releases/download/v1.8.0/SHA256SUMS.txt).

Статусы по вставленному снимку. Равные номера в таблице не означают связь button.
Существующая пустая/FREE секция исключена из свободных номеров секций.
max-ephones ограничивает число аппаратов. Работа переадресаций и регистрация по сети
не проверяются. SIP/другие поля шаблонов не моделируются полностью; ограничения
раскрыты в [документации CUCME](https://github.com/F1ourish/network-tools/blob/main/docs/CUCME.md).
Целевая среда - Windows 10/11 x64; нативный стенд - Windows Server CI.
