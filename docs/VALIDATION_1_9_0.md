# Проверка Network Tools 1.9.0

Дата: 20.10.2026. Статус: кандидат; результаты Windows и публикации ожидаются.

- Linux Ruff check/format и 653 теста без GUI успешны.
- Полный Windows набор: 829 тестов, включая 176 GUI.
- Проверка готового EXE предусматривает 82 нативных проверки.
- Подтверждённые результаты конкретной сборки будут в RELEASE_VERIFICATION.json и artifacts CI.

## Проверка адреса

Проверены точное сопоставление ARP, Incomplete/FAILED/STALE, отсутствие записи,
пересечения с исключениями, границы коротких/полных диапазонов, сеть/broadcast,
выход за подсеть и наличие в ARP вне неё. Для всех 256 позиций /24 результат
сверен с полным списком кандидатов. Проверены /23, /31, /32 и /1, ноль кандидатов,
неверный IPv4/CIDR/IPv6, пробелы и несколько адресов вместо одного.

GUI проверяет отдельный пересчёт запроса без сброса ARP/страницы, немедленную
очистку прежней проверки при изменении данных, восстановление, пустой/ошибочный
ARP, вставку, копирование отчёта, обе темы и сохранение только темы.
Нативный EXE повторяет поиск, ограничения и изменение ARP/исключений/запроса.

Публичные примеры и снимки используют тестовые адреса.
Целевая среда - Windows 10/11 x64; нативный стенд - Windows Server CI.
Клиентские Windows, DPI 125-200%, Wine и macOS отдельно не проверялись.
