## Проверенные изменения

Кнопка «Развернуть отчёт» и Ctrl+Enter открывают одно отдельное окно CUCME.
Проверены размер окна, readonly, точное копирование, страницы, темы, повторное
открытие, Escape и удаление виджета при закрытии. Конфиг сохраняется.
Открытый отчёт следует за запросом, режимом и страницей; ошибка ввода,
редактирование и явная очистка удаляют устаревший результат из обоих окон
и отключают копирование. Обработчик неожиданной ошибки также очищает окно.

Карточки подписывают номер секции, описание, телефонный номер (number),
дополнительный secondary, имя/подпись, модель и MAC. Замечание о незаполненном
аппарате содержит description и называет только фактически отсутствующие поля.
Синтетический ephone 38 с description FREE виден как существующая секция,
его номер не попадает в список свободных номеров секций.
Для синтетического DN 202 прямо в замечании сверены number 31202 и description
31201, пояснение полей и указание, что различие само по себе не означает ошибку.
Замечания явно относятся ко всей конфигурации и разделены на абзацы;
ограничение 20 показывается при превышении, полный счётчик сохраняется.

Нативная проверка готового EXE подтвердила открытие максимизированного окна
по Ctrl+Enter, readonly и точное совпадение clipboard с основной вкладкой.
Проверены запрос ephone 38 с описанием FREE, показ отдельных number/description,
обновление открытого отчёта при запросе, отключение копирования после ошибки
конфига и восстановление после исправления. Escape и повторное открытие
сохраняют текущий результат и конфиг. Прежние проверки инструментов сохранены.
Снимки опубликованного EXE просмотрены; источник: [описание снимков](screenshots/README.md).

Publisher сверил source commit и assets одного CI run. Размеры и SHA-256
опубликованных файлов совпадают со скачанными artifacts. EXE и отчёт внутри ZIP
совпадают с отдельными assets; все контрольные суммы проверены.

[`RELEASE_VERIFICATION.json`](https://github.com/F1ourish/network-tools/releases/download/v1.7.1/RELEASE_VERIFICATION.json)
и [`SHA256SUMS.txt`](https://github.com/F1ourish/network-tools/releases/download/v1.7.1/SHA256SUMS.txt).

Анализируется предоставленный конфиг; регистрация телефонов по сети не проверяется.
Целевая среда - Windows 10/11 x64; нативный стенд - Windows Server CI.
Клиентские Windows и DPI 125-200% требуют отдельной проверки. EXE без цифровой подписи.
